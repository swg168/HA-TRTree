# HA-TRTree

This repository contains simulation and empirical analysis materials for HA-TRTree.

## Files

- `simulaiton_code.zip` — simulation code, including R scripts, Stan models, and supporting data files. The original archive filename is preserved.
- `empirical_code.zip` — empirical analysis code, including R scripts, Stan models, and prepared data.

Download and extract each ZIP archive to access the corresponding scripts and files.
